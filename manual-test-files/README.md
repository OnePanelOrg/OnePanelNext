# Manual upload fixtures

Each `sample.*` file is a valid example of an extension accepted by
`src/lib/upload-selection.mjs`.

- Upload `sample.cbz`, `sample.cbr`, `sample.zip`, `sample.rar`, and
  `sample.pdf` one at a time. Each contains three numbered pages.
- Select all eight standalone image files together to test filename ordering
  and mixed image formats: BMP, GIF, JPEG, JPG, PNG, TIF, TIFF, and WebP.
- The `pages/` directory contains the three PNG source pages used to build the
  archives; it is not an additional format fixture.

Expected result: every upload finishes without getting stuck in a loading
state, and the reader shows pages in numeric filename order (blue, red, green).

`sample.rar` and `sample.cbr` are generated separately with RAR. The other
fixtures can be regenerated by running `generate_fixtures.py` with Pillow and
ReportLab installed.
